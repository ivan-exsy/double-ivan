### Likely upstream cause (hypothesis — next eng probe)

**Not** “migration missing”: `update_avatar_position_dev(..., p_actual_path)` exists on prod; writeback never got non-empty paths.

| Item | Value |

| `HEADLESS_STRICT_ABORT` | `false` (run continued despite 0/15) |
| `_set_collision_sim_id_override` | Only set in **Supabase read-only** bootstrap — **not** on normal score start |

### A/B probe result

| URL | `__headlessReady` | `collisionManagerBound` | Notes |
|-----|-------------------|------------------------|-------|
| `…?headless=true` (no `sim_id`) | **false** | **false** | `reason=awaiting_collision_manager`; console: **Failed to resolve simulation ID** + `ERR_NAME_NOT_RESOLVED` to FE Supabase host |

With `sim_id`, ready flips **true**, but maze **chunk RPCs still fail** (`ERR_NAME_NOT_RESOLVED` to `jawqll…`) → `chunksLoaded=0`, `dataReady=false`. So fixing URL `sim_id` alone may get acceptance of the ready contract; **wall-aware paths still need reachable maze/collision data** (point FE at BE Supabase, or Playwright intercept, or shared DNS).

### Root-cause pick (ordered)

1. **P0a — Missing `sim_id` on score headless URL**  
   Normal score path never calls `_set_collision_sim_id_override` → FE never gets UUID from query → waits forever for collision bind → `accepted=0/15`.

2. **P0b — FE Supabase unreachable / wrong project on VPS**  
   FE env points at `jawqll…` which **does not resolve** from the VPS; BE score data lives on `kkjh…`. Name→UUID RPC fails without `sim_id`; chunk loads fail even with `sim_id`.

3. **P0c — No fail-fast**  
   `HEADLESS_STRICT_ABORT=false` allowed ~2k steps of intent-only motion.

4. **P2 — Stale VPS FE build** (`21371fa`) — not required to explain ready=false once `sim_id` is present; still upgrade before next score ship.
