### 8. Test suite health — 76 pre-existing failures

**State:** the suite reports **76 failing entries** (~72 failures + 4 errors; the count wobbles ±1 between runs). Three more files are excluded outright for collection errors: `run_debug_test.py`, `test_address_validation.py`, `test_movement_continuity.py`.

**None of these were introduced by 1-A.** Proven by running the full suite with and without the changes back to back in the same working copy — identical failure sets, twice.

**Two traps, both hit during 1-A — write these down:**

- A **fresh `git worktree` is not a valid baseline.** Several trailer and deployment tests depend on untracked local data a clean checkout does not have, so the same commit fails differently in two directories. Always compare via `git stash` in the *same* working copy.
- Some failures are **order-dependent**, not deterministic. `plan.py` uses the try/except dual-import pattern, so a symbol may or may not be a module attribute depending on which test imported the backend first. A test can pass alone and fail in the suite.

**Why this matters now:** with 76 standing failures, a real regression can hide in the noise, and proving innocence costs three full suite runs (~4 minutes of compute plus stash choreography) per change. That is a tax on every future fix, and it is the reason 1-A's verification took as long as the code.

**Recommended cleanup — after 1-A scores green, not before:**

- [ ] Triage the 76 into buckets: (a) genuinely broken code, (b) tests asserting behaviour we deliberately changed and never updated, (c) environment/data-dependent, (d) order-dependent
- [ ] Fix or delete bucket (b) — stale assertions are worse than no test; they train everyone to ignore red
- [ ] Mark bucket (c) with `skipif` on the missing fixture so a clean checkout is honest
- [ ] Fix bucket (d) with `raising=False` / proper fixtures so suite order stops mattering
- [ ] Re-enable the three excluded files or delete them
- [ ] **Target: a green suite**, so "did I break something" is one run and one glance

Do **not** start this before the score. It touches many files, it competes for attention with the gate, and a red suite is a known quantity today.
