# Reference Materials — Day 1 Trailer

This folder contains the core visual and brand assets you should use to produce the polished vertical trailer.

## Contents

### hero_images/
High-resolution realistic portraits of the main cast (Pistsov family).  
Use these for the cast-intro cards at the top of the trailer.

### sketches/
Character sketch portraits (Ivan, Katya, Gosha).  
These appear in the alternating top corners during the main arc scenes.

### brand/
Official brand assets:
- `opening_wordmark-no-h2.png` — Clean DOUBLAND wordmark for the opening title card
- `brand_end_card.png` and `brand_end_card_background.png` — End-card graphics

### moodboard/
Selected style reference frames showing the intended visual language for village exteriors, interiors, and typography treatments.

### creative_spec.md
Simplified creative guidelines written specifically for video editors.  
This is your primary reference for structure, tone, narration rules, and brand discipline.

---

All materials are ready to use. Re-use existing raw footage, narration, and music from the parent folder wherever possible. The goal is to elevate the current rough cut to production quality while staying on-brand.

If anything is missing or unclear, let me know.
