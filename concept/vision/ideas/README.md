# Vision ideas — capture & triage

**Purpose:** Hold founder ideas that might improve Vision Canon *or* wait for later — without dumping raw brainstorms into `north-star.md`.

**Where:** `double-ivan/concept/vision/ideas/`  
**Canon stays locked** until you explicitly approve a promote.

---

## Loop (repeat anytime)

1. **Capture** — Paste ideas in chat (`@cos` + “vision idea”) *or* drop a file from [`_template.md`](_template.md) into this folder with `status: inbox`.
2. **Triage (COS)** — For each idea: one-line summary, tension with current Canon (if any), recommended lane:
   - **promote** — draft exact patch to `north-star` / `pillars` / `mission` / `vc_msg`
   - **candidate** — strong, but needs a founder call (tension or scope)
   - **park** — keep for future; do not change Canon
   - **reject** — out of scope / conflicts with non-goals (rare)
3. **Decide (you)** — Reply `promote <id>`, `park <id>`, `reject <id>`, or `edit …`.
4. **Commit (COS)** — On promote: patch Canon, set idea `status: incorporated` + link the commit paths. On park/reject: update frontmatter only.

**Rule:** Auto-propose patches OK; **never** silent Canon edits.

---

## Status legend

| Status | Meaning |
|--------|---------|
| `inbox` | Captured; not triaged |
| `candidate` | Triaged; waiting on your call |
| `promote-ready` | Patch drafted; waiting approve |
| `incorporated` | Merged into Canon (see `incorporated_into`) |
| `parked` | Future consideration; not Canon |
| `rejected` | Explicitly not pursuing |
