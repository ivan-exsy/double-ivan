## How to use

1. **Any product task** → `mission.md` + this index (know Canon vs Draft).
2. **Long-term / roadmap / “should we build X?”** → `mission.md` → `vision/pillars.md` → `vision/alignment-rubric.md`.
3. **New vision ideas (founder dump)** → `vision/ideas/` (capture → COS triage → you promote/park). Do not paste raw inbox into Canon.
4. **VC / promo drafts** → `mission.md` + `vc_msg.md` (memo + spoken room locks). In a room, do not mix the memo’s ARR/MAU/COGS figures into the mouth. Moneyball only if sports GTM. Ready-to-send → founder `pending_approval`.
5. **Scaling architecture bets** → may *consult* `v1_opensource/` as Draft only; flag undecided in every report.
