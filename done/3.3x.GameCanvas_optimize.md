## **Implementation Plan: Modular Architecture (Option B)**

### **Goal**
Refactor `GameCanvas.tsx` and `MainScene.ts` into a modular "Manager" pattern. This restores legacy functionality (movement, chat, proximity) and preserves new Story Stream features (auto-follow, subtitles) while preventing `MainScene.ts` from becoming a "God Class".

### **Architecture Overview**
1.  **`scenes/MainScene.ts`** (Orchestrator)
    *   Initializes managers.
    *   Delegates `update()` calls.
    *   Handles Phaser lifecycle (`preload`, `create`, `destroy`).
    *   Owns the `spriteGroup` and `camera`.

2.  **`scenes/managers/AnimationManager.ts`**
    *   **Source**: Legacy `MultiStepAnimationManager` logic from `GameCanvas-vercel.tsx`.
    *   **Role**: Handles step interpolation, tween management, idle animations, and path smoothing.
    *   **Improvement**: Decoupled from React state; accepts pure data objects.

3.  **`scenes/managers/InteractionManager.ts`**
    *   **Source**: Legacy `setupObservationDetection` and `resolveCharacterCollision`.
    *   **Role**: Handles physics collisions, proximity checks (throttled), and reporting events back to React via callbacks.

4.  **`scenes/managers/CameraManager.ts`** (New, extraction from MainScene)
    *   **Source**: Story Stream `autoFollow`, `dramaFilter` logic.
    *   **Role**: Manages camera focus, zoom levels, and "Director Mode" logic.

5.  **`components/MultiSpeechController.ts`** (Existing)
    *   **Integration**: Instantiated in `MainScene`, updated in game loop.
