### 3.2 RCA-S1 — Cafe talk-loop / CD violations

**Viewer symptom:** Same pairs re-open chat constantly at Hobbs; cafe feels like a broken talk loop.

**Prior RCA root (greeting floor / Irene↔Max):** Wrong emphasis.

**Revised ranked roots:**

| Rank | Hypothesis | Status |
|-----:|------------|--------|
| **1** | **Proximity architecture:** co-location + overlap → `should_chat` with no willingness gate; every CD expiry reopens | **Primary (product)** |
| **2** | **End-path CD:** depth tier 5 + cafe `cooldown_mod=-2` → **3**; start-path floor never reaches `set_cooldown` for full chats | **Primary (patch miss)** |
| **3** | Analyzer inflation: greetings lack stable `conversation_id` → gap=0 dual counting (~335) | **Inflates score** |
| **4** | Irene↔Max special case | **False** — no code path; only 18/946 |

**Why the CD floor patch failed / looked worse:**

1. Floor lives in `should_converse` → `params.cooldown_steps`.
2. Greetings stamp that value; **full chats stamp only in `end_conversation`**, which ignores `computed_cooldown` (R4 depth-only).
3. Cafe end path still produces CD=3 → analyzer `effective_cooldown=3` (229 hits).
4. Longer score window + unchanged reopen policy → 809→946.

**Desired (Track S):**

- Full talk when willing (intent / affinity / agenda).
- When willing, may **seek** (generalize beyond Survival-only seek).
- Proximity alone → **brief greeting** + real cooldown — not full-chat spam.
- CD floor after arena mod on **end** path is hygiene, not the strategy.
