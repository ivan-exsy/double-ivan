# **Partial Rollback: Turn-Based Scenario-Movie Approach**

## *Vision*

The turn-based architecture transforms the generative agents simulation into an interactive, emergent system where:
- the backend generates immutable JSON "scripts" for each step (agent decisions, partial movements, actions), 
- the frontend visualizes these in real-time using Phaser for realistic sprite behaviors, and reports back observations (e.g., unplanned collisions or serendipitous encounters) to influence future steps. 
This enables natural social interactions, spontaneous events, and personalized user experiences — users can focus on specific agents, adjust camera angles, and witness emergent storytelling. 
Headless rendering serves for initial synchronization and validation, ensuring backend plans render correctly without glitches, while the core experience is live, re-renderable simulations that feel dynamic and agent-driven rather than pre-recorded movies.

## *Schema*

Step N: Backend generates agent decisions + partial movements
      ↓
Step N: Frontend renders movements + collects user interactions
      ↓ 
Step N+1: Backend processes interactions + continues simulation

  *Key Benefits*
1. Natural Time Flow: Actions can span multiple steps naturally
2. Realistic Movement: 6 tiles/minute speed limit enforced naturally
3. Social Interactions: Real-time reaction between agents
4. User Interaction: Frontend can inject events between steps
5. Simplified State Management: Single source of truth

```python
def execute_immutable_step(self, step_number, user_interactions=None):
    """Execute step with immutable state management and movement constraints"""
    # 1. Read previous step state (never modify existing files)
    previous_step_data = self.read_previous_step_state(step_number - 1)
    
    # 2. Process user_interactions before cognitive pipeline
    if user_interactions:
        self.process_user_interactions(user_interactions, previous_step_data)
    
    # 3. Execute cognitive pipeline with movement constraints
    movements = {}
    for persona_name, persona in self.personas.items():
        # Load previous partial state
        previous_state = previous_step_data.get(persona_name, {}).get('partial_state', {})
        
        # Execute with 6 tiles/minute constraint
        movement_result = self.execute_constrained_movement(persona, previous_state)
        movements[persona_name] = movement_result
    
    # 4. Create immutable step file with embedded state
    self.create_step_with_embedded_state(step_number, movements, user_interactions)
    
    # 5. Return step completion status (never modify existing data)
    return {
        "step_completed": True,
        "step_number": step_number,
        "movements": movements,
        "immutable_guarantee": True
    }
```

```python
import asyncio
from playwright.async_api import async_playwright

class HeadlessVisualizationService:
    async def render_step_async(self, sim_code: str, step_number: int):
        """Render step visualization in background"""
        async with async_playwright() as p:
            browser = await p.chromium.launch(headless=True)
            page = await browser.new_page()
            
            # Load React frontend with specific step
            await page.goto(f"http://localhost:3000/simulations/{sim_code}?step={step_number}&headless=true")
            
            # Wait for Phaser.js to fully render the step
            await page.wait_for_selector('[data-testid="phaser-canvas-ready"]')
            
            # Capture the rendered frame
            screenshot = await page.screenshot(
                path=f"storage/{sim_code}/rendered/{step_number}.png",
                full_page=True
            )
            
            await browser.close()
            
            # Update step metadata with render status
            await self.update_step_render_status(sim_code, step_number, "completed")
            return screenshot
            
    async def batch_render_simulation(self, sim_code: str):
        """Render entire simulation as video/image sequence"""
        total_steps = await FileService.get_simulation_step_count(sim_code)
        
        # Process steps in parallel for faster rendering
        tasks = [
            self.render_step_async(sim_code, step) 
            for step in range(total_steps)
        ]
        
        await asyncio.gather(*tasks, return_exceptions=True)
        
        # Generate MP4 video from image sequence
        await self.create_simulation_video(sim_code, total_steps)
```

```python
def execute_partial_movement(persona, max_tiles=6, previous_state=None):
    """Execute partial movement with immutable state tracking"""
    # Read previous state from last step file (never modify existing)
    remaining_path = previous_state.get('remaining_path', []) if previous_state else []
    
    if remaining_path:
        # Continue previous movement
        consumed = min(max_tiles, len(remaining_path))
        next_position = remaining_path[consumed-1]
        new_remaining_path = remaining_path[consumed:]
        
        # Return new state (to be embedded in step file)
        return {
            'position': next_position,
            'partial_state': {
                'remaining_path': new_remaining_path,
                'consumed_tiles': consumed,
                'step_type': 'continuing_movement'
            }
        }
```

```python
def calculate_action_progress(self, current_step, previous_state=None):
    """Calculate action progress immutably from step history"""
    action_start_step = previous_state.get('action_start_step', current_step) if previous_state else current_step
    steps_elapsed = current_step - action_start_step
    
    progress = {
        'action_start_step': action_start_step,
        'steps_elapsed': steps_elapsed,
        'action_completed': steps_elapsed >= self.act_duration,
        'progress_percentage': min(100, (steps_elapsed / self.act_duration) * 100)
    }
    return progress
```

```python
def create_step_with_embedded_state(self, step_number, movements, user_interactions=None):
    """Create immutable step file with all state embedded"""
    step_data = {
        "persona": {},
        "meta": {
            "curr_time": self.curr_time.strftime("%B %d, %Y, %H:%M:%S"),
            "step_number": step_number,
            "user_interactions": user_interactions or {},
            "timestamp": datetime.now().isoformat()
        }
    }
    
    # Embed partial states in each persona's data
    for persona_name, movement in movements["persona"].items():
        step_data["persona"][persona_name] = {
            **movement,  # movement, path, description, etc.
            "partial_state": {
                "remaining_path": getattr(self.personas[persona_name].scratch, 'remaining_path', []),
                "action_progress": self.calculate_action_progress(persona_name, step_number),
                "movement_state": getattr(self.personas[persona_name].scratch, 'movement_state', {})
            }
        }
    
    # Write immutable step file
    step_file = f"{self.sim_folder}/movement/{step_number}.json"
    with open(step_file, "w") as outfile:
        outfile.write(json.dumps(step_data, indent=2))
```

### **🔒 Immutability & Replay Guarantees**

1. **Write-Once Step Files**: Each step creates a uniquely numbered file that is never modified
2. **Embedded State Management**: All partial states are embedded within step files, not separate mutable files  
3. **Append-Only Architecture**: System only adds new steps, never modifies existing ones
4. **API Immutability Contracts**: All endpoints guarantee no backward modification

1. **Complete Historical Access**: Every step's data permanently stored with full context
2. **Partial State Tracking**: Detailed progress information embedded in each step
3. **User Interaction History**: All user inputs logged immutably within step files
4. **Rich Replay Context**: Step files contain everything needed to reconstruct exact simulation state

## **Part 5: Enhanced Feedback Loop**:

### Process
1. **Backend Script Generation**: reverie.py creates immutable step JSONs with plans (A* paths, action durations, partial states like remaining_path). Endpoint: POST /step/next.
2. **Frontend Visualization**: Phaser renders the step live—animates movements, detects physics events (collisions, proximity), and handles emergent interactions (e.g., sprites meeting half-way).
3. **Observation Reporting**: Frontend sends feedback (e.g., {type: "serendipitous_meeting", agents: ["Maria", "Klaus"], location: [x,y]}) via POST /observations.
4. **Backend Adjustment**: Next step incorporates observations (e.g., trigger conversation action, adjust paths), maintaining immutability (only future steps change).
5. **Headless Validation**: Initial dry-run (batch headless via Playwright) syncs backend plans with frontend rendering, flagging mismatches (e.g., visual glitches) before user sessions.

### Benefits
- **Emergent Realism**: Enables spontaneous behaviors (e.g., half-way meetings, environmental reactions) that static PNGs/movies can't capture.
- **Personalization**: Users re-render live with custom views (follow specific sprite, multiple angles), fostering engagement and ownership.
- **Efficiency**: Backend computes AI once; frontend handles interactive viz. Feedback loop ensures plans stay realistic without full re-simulation.
- **Serendipity**: Supports app's core goal—natural agent interactions, social dynamics, and storytelling from simple rules.
