No automatic slowdowns—users manage speeds manually. Focus on Phaser.js for animation scaling and WebSocket sync for data flow.

- Store the selected speed in state (e.g., useSimulation hook) and expose it to the rendering loop.
- Default to x1 for initial realism.

#### Step 2: Implement Proportional Animation Scaling in Phaser.js
- In the Phaser scene (e.g., GameCanvas.tsx), modify movement tweens/interpolation to scale based on the current speed multiplier.

- Use Phaser's tween system with easing (e.g., Linear) for smooth paths; adjust frame rates or step sizes proportionally to avoid glitches.
- Handle stationary actions by scaling idle animations or timers similarly.

#### Step 3: Ensure Backend-Frontend Synchronization
- Use WebSocket (ws://localhost:8001/ws/simulations/{sim_code}/movement) to receive real-time step updates without blocking.

- Add logic to pause/resume backend simulation if needed (via API endpoint) to prevent desync, ensuring animations complete before loading the next step.
